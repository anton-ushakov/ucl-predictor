# ucl-predictor: бэкенд

Сервер для прогнозов на матчи Лиги чемпионов среди друзей.
Стек: Java, Spring Boot 4.1, PostgreSQL, Flyway, Maven.
Список всех запросов с примерами: [API.md](API.md).

## Запуск

1. База данных PostgreSQL: создайте базу `ucl_predictor` (`CREATE DATABASE ucl_predictor;`).
2. Откройте проект в IntelliJ IDEA как Maven-проект (File → Open → `pom.xml` → Open as Project).
3. В `src/main/resources/application.properties` проверьте адрес базы (порт!) и пользователя.
4. Секреты задавайте переменными окружения, а не в файлах проекта:
   Run → Edit Configurations → `PredictorApplication` → Environment variables:

   ```
   DB_PASSWORD=пароль_postgres;FOOTBALL_DATA_TOKEN=токен_football-data.org
   ```

   (несколько переменных разделяются точкой с запятой). Токен нельзя выкладывать в чат, в git и в архивы.
5. Запустите `PredictorApplication`. Flyway сам применит миграции из `db/migration`.

Через 20 секунд после старта приложение загрузит матчи из football-data.org (дальше раз в 30 минут) и
подведёт итоги завершённых туров. В логе появится строка вида `Матчи обновлены: получено ...`.
Если токен не задан, в логе будет предупреждение, а матчи не загрузятся.

## Устройство

- `feed/`: загрузка матчей из football-data.org и фоновая задача
- `round/`: туры, приём прогнозов пачкой, правила показа чужих прогнозов, подведение итогов, история
- `group/`: группы, роли, настройки, правила тура
- `standings/`: подсчёт таблицы тура, общий зачёт
- `scoring/`: баллы за прогноз (точный счёт 3, исход 1)
- `membership/`: приглашения в группу и заявки на вступление
- `notify/`: оповещения (подготовка, список, настройки)
- `auth/`: регистрация, вход, токены, смена пароля и восстановление доступа
- `db/migration/`: схема базы (V1 основа, V2 токены, V3 туры, настройки, история, V4 счёт по частям: основное/добавочное/пенальти, V5 решения группы по матчам без полных данных, V6 восстановление доступа, V7 режим сдачи прогнозов, V8 оповещения, V9 простой вход и заявки, V10 уникальность имени, V11 настройка баллов)

## Тесты

`mvn test` или правая кнопка на папке `src/test` → Run Tests. Проверяются баллы, таблица тура и
дополнительные показатели, общий зачёт, проверка пачки прогнозов, правила показа, разбор данных
football-data.org.

## Необязательные настройки (`application.properties`)

| Свойство | По умолчанию | Смысл |
|---|---|---|
| `app.timezone` | `Europe/Moscow` | часовой пояс, по нему считаются недели |
| `app.predictions.weeks-ahead` | `1` | на сколько недель вперёд открыт приём прогнозов |
| `app.football-data.sync-interval` | `PT30M` | как часто обновлять матчи (формат ISO, например `PT15M`) |
| `app.football-data.competition` | `CL` | код турнира в football-data.org |
