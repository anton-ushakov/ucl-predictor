# Сервер на домашнем ноутбуке

Два этапа. Сначала запускаем всё дома и проверяем с телефона по Wi-Fi. Потом, когда убедимся,
что работает, открываем доступ из интернета через Cloudflare Tunnel.

---

# Этап 1. Запуск в домашней сети

## 1.1. Подготовить ноутбук

Подключите его к роутеру кабелем.

Отключите засыпание, иначе сервер будет пропадать:

- Параметры → Система → Питание и спящий режим: в обоих списках выберите «Никогда».
- Панель управления → Электропитание → «Действие при закрытии крышки»: при работе от сети
  поставьте «Действие не требуется». Тогда ноутбук можно закрыть и убрать под стол.

## 1.2. Установить Docker Desktop

Скачайте с https://www.docker.com/products/docker-desktop и установите.
Если предложит включить WSL 2 — соглашайтесь, это обязательный компонент.
После установки потребуется перезагрузка.

Проверка: откройте PowerShell и выполните

    docker --version

## 1.3. Скопировать проект

Перенесите папку проекта на ноутбук любым способом: флешкой, по сети, через облако.
Внутри должны быть `pom.xml`, `src`, `Dockerfile`, `docker-compose.home.yml` и остальные файлы.

## 1.4. Заполнить секреты

В папке проекта откройте PowerShell (правой кнопкой по пустому месту в папке → «Открыть в терминале»):

    copy .env.example .env
    notepad .env

Заполните:

    DB_PASSWORD=придуманный_длинный_пароль
    FOOTBALL_DATA_TOKEN=ваш_токен
    WEEKS_AHEAD=4
    APP_TIMEZONE=Europe/Moscow

Остальные строки пока оставьте пустыми. Сохраните файл и закройте блокнот.

## 1.5. Запустить

    docker compose -f docker-compose.home.yml up -d --build

Первая сборка займёт несколько минут. Посмотреть, как идут дела:

    docker compose -f docker-compose.home.yml logs -f app

Ждём строку `Started PredictorApplication`. Выйти из просмотра: Ctrl+C.

## 1.6. Открыть порт в брандмауэре

Чтобы телефоны увидели сервер, выполните в PowerShell **от имени администратора**:

    New-NetFirewallRule -DisplayName "Shaurma League" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow

## 1.7. Узнать адрес ноутбука

    ipconfig

Найдите «IPv4-адрес» у проводного подключения, это что-то вроде `192.168.0.105`. Запишите его.

Проверьте в браузере на самом ноутбуке:

    http://localhost:8080/api/groups

Ответ `{"status":401,...}` означает, что всё работает.

## 1.8. Настроить приложение

В Android Studio откройте `data/ServerConfig.kt` и впишите адрес ноутбука:

    const val BASE_URL = "http://192.168.0.105:8080/"

Затем откройте `app/src/main/res/xml/network_security_config.xml` и замените там строку
с примером `192.168.1.50` на свой адрес:

    <domain includeSubdomains="false">192.168.0.105</domain>

Соберите приложение заново. Телефон должен быть в той же сети Wi-Fi.

Теперь всё работает дома: друзья в гостях смогут играть, а из интернета сервер пока не виден.

# Этап 2. Доступ из интернета через Cloudflare Tunnel

Ноутбук сам устанавливает соединение с Cloudflare. Порты на роутере пробрасывать не нужно,
статический адрес не нужен, и ноутбук остаётся невидимым из интернета. HTTPS выдаёт Cloudflare.

Нужен домен. Если своего нет, купите на cloudflare.com (около 10 $ в год за `.com`).

## 2.1. Завести домен в Cloudflare

1. Зарегистрируйтесь на cloudflare.com.
2. Купите домен в разделе Domain Registration либо перенесите уже купленный.

## 2.2. Создать туннель

1. В панели Cloudflare откройте Zero Trust → Networks → Tunnels.
2. Create a tunnel → тип Cloudflared → имя, например `shaurma`.
3. На шаге установки вам покажут команду с длинным ключом. Сам ключ — это строка после
   `--token`, вида `eyJhIjoiXXXX...`. Скопируйте только её.
4. На вкладке Public Hostname добавьте запись:
   - Subdomain: `app` (или оставьте пустым, чтобы использовать сам домен)
   - Domain: ваш домен
   - Service Type: `HTTP`
   - URL: `app:8080`

## 2.3. Запустить туннель

В файле `.env` на ноутбуке заполните строку:

    TUNNEL_TOKEN=eyJhIjoiXXXX...

И перезапустите с туннелем:

    docker compose -f docker-compose.home.yml --profile tunnel up -d

Проверьте в браузере с телефона по мобильному интернету:

    https://app.ваш-домен.com/api/groups

## 2.4. Переключить приложение

В `ServerConfig.kt`:

    const val BASE_URL = "https://app.ваш-домен.com/"

Соберите заново. Теперь приложение работает откуда угодно, а оповещения приходят сами.

# Повседневное

Посмотреть состояние:

    docker compose -f docker-compose.home.yml ps

Логи:

    docker compose -f docker-compose.home.yml logs -f app

Перезапустить:

    docker compose -f docker-compose.home.yml restart app

Обновить после моих правок (заменив файлы проекта):

    docker compose -f docker-compose.home.yml up -d --build

Резервная копия базы:

    docker compose -f docker-compose.home.yml exec -T db pg_dump -U predictor ucl_predictor > backup.sql

Восстановить из копии:

    Get-Content backup.sql | docker compose -f docker-compose.home.yml exec -T db psql -U predictor ucl_predictor

После перезагрузки ноутбука контейнеры поднимутся сами, если в Docker Desktop включён запуск
при старте Windows (Settings → General → Start Docker Desktop when you sign in).
